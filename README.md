## ✨ 简介
一套结构化的提示词集合，可引导AI生成包含**图片转换、网格编辑器、色号匹配、用量统计与图纸导出**等功能的H5拼豆工作台。

## 🚀 使用方法
1. 复制提示词到AI工具（ChatGPT / Claude 等）
2. 获取生成的 HTML / CSS / JS 代码
3. 保存为 `.html` 文件，浏览器打开即用

## 🎯 提示词示例

| 名称 | 功能 | 难度 |
| :--- | :--- | :--- |
| **基础图像转换** | 图片上传、网格预览、色号匹配 | ![初级](https://img.shields.io/badge/难度-初级-green) |
| **交互式编辑器** | 画笔、橡皮擦、吸色器等编辑工具 | ![中级](https://img.shields.io/badge/难度-中级-yellow) |
| **专业导出系统** | 导出PNG/PDF图纸与CSV材料清单 | ![高级](https://img.shields.io/badge/难度-高级-red) |

## 🛠️ 生成结果
基于原生 **HTML5 + CSS3 + JavaScript**，无任何依赖，开箱即用。

**工作流：** 📸 上传图片 → ⚙️ 调整参数 → 🎨 智能转换 → 👁️ 编辑预览 → 📄 导出图纸 → 🧩 开始制作
